## Day 2 – Order Performance and Business Insights

**Project Topic:** Order Performance and Business Insights

**Goal:** Understand order performance, identify issues, and improve business decisions using SQL.

**Role:** Junior Data Analyst – Online Store

### Tasks Completed
- Counted the total number of orders.
- Analyzed order status distribution.
- Analyzed daily order trends.
- Analyzed monthly order trends.
- Identified top customers.
- Analyzed high-value orders.
- Explored order performance using SQL queries.
- Derived business insights and recommendations.

### Key Insights
- **Total Orders:** The store recorded 3,000 orders.
- **Order Status:** 1,796 orders were delivered, 280 were returned, and 236 were cancelled.
- **Monthly Trends:** August recorded 300 orders in the analyzed results.
- **Customer Analysis:** Ranked customers based on the selected order metric.
- **Order Value:** Identified high-value orders for further business analysis.

### Business Recommendations
- Investigate the reasons for returned and cancelled orders.
- Monitor order trends to support business planning.
- Analyze customer purchasing patterns.
- Track order fulfilment to improve operational efficiency.
